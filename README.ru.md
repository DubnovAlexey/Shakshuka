# Шакшука

[English](README.md) · [עברית](README.he.md) · **Русский**

Рецепт шакшуки — традиционного израильского завтрака — на одной странице: фотогалерея, ингредиенты с картинками, приготовление по шагам и советы. Домашнее задание по HTML и CSS с курса Full Stack.

**Демо:** https://dubnovalexey.github.io/Shakshuka/

## Что внутри

- Таблица-галерея, список ингредиентов с картинками, пронумерованные шаги и заметки.
- Семантический HTML: заголовки, списки, таблица, `<strong>` и `<i>`.
- Адаптивные картинки (`max-width: 100%`, `aspect-ratio`) и ленивая загрузка — страница помещается на телефоне.

## Стек

HTML5 · CSS3 · GitHub Pages

## Как запустить

Откройте `index.html` в браузере.

## Планы

- Хранить фотографии в проекте (свои или со свободной лицензией), а не ссылаться на чужие сайты.
- Версия на иврите и русском с переключателем языка.
