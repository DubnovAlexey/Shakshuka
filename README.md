## English

A one-page recipe of shakshuka, the traditional Israeli breakfast: a photo gallery, the ingredients with pictures, step-by-step cooking and tips. A responsive HTML and CSS recipe presentation.

**Live demo:** https://dubnovalexey.github.io/Shakshuka/

### Try it

Read the ingredient list and follow the numbered cooking steps. Compare the gallery and ingredient images on a narrow and a wide screen.

### What is inside

- A gallery table, an ingredient list with images, numbered steps and notes.
- Semantic HTML: headings, lists, a table, `<strong>` and `<i>`.
- Responsive images (`max-width: 100%`, `aspect-ratio`) and lazy loading, so the page fits a phone.

### Tech stack

HTML5 · CSS3 · GitHub Pages

### Run locally

Open `index.html` in a browser.

### Demo scope

The recipe page itself is currently in English; the three README versions translate its documentation. Photos load from external sites, and timers or portion controls are not implemented yet.

### Further development

Proposals below are planned work, not existing features.

- Visual: turn cooking steps into readable cards, align image proportions and add a small pan favicon.
- Engineering: replace remote image dependencies with authorized local images and explicit dimensions; check alt text and local asset paths.
- Features: add portion scaling, step timers and an on-page language switch with text-only language names.

## Русский

**Шакшука**

Рецепт шакшуки — традиционного израильского завтрака — на одной странице: фотогалерея, ингредиенты с картинками, приготовление по шагам и советы. Домашнее задание по HTML и CSS с курса Full Stack.

**Демо:** https://dubnovalexey.github.io/Shakshuka/

### Попробовать

Просмотрите ингредиенты и пройдите по пронумерованным шагам приготовления. Сравните галерею и изображения ингредиентов на узком и широком экранах.

### Что внутри

- Таблица-галерея, список ингредиентов с картинками, пронумерованные шаги и заметки.
- Семантический HTML: заголовки, списки, таблица, `<strong>` и `<i>`.
- Адаптивные картинки (`max-width: 100%`, `aspect-ratio`) и ленивая загрузка — страница помещается на телефоне.

### Стек

HTML5 · CSS3 · GitHub Pages

### Как запустить

Откройте `index.html` в браузере.

### Границы демонстрации

Сама страница рецепта пока на английском; три README переводят документацию. Фотографии загружаются со сторонних сайтов, таймеров и пересчёта порций пока нет.

### Дальнейшее развитие

Ниже перечислены предложения, а не уже реализованные функции.

- Визуал: читаемые карточки шагов, одинаковые пропорции изображений и малый favicon сковороды.
- Инженерия: разрешённые локальные фотографии вместо внешних зависимостей, явные размеры и проверка alt/путей ресурсов.
- Функции: пересчёт порций, таймеры этапов и переключатель языка страницы с текстовыми названиями языков.
