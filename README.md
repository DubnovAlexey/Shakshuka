# Shakshuka

**English** · [עברית](README.he.md) · [Русский](README.ru.md)

A one-page recipe of shakshuka, the traditional Israeli breakfast: a photo gallery, the ingredients with pictures, step-by-step cooking and tips. An HTML and CSS homework from my Full Stack course.

**Live demo:** https://dubnovalexey.github.io/Shakshuka/

## What is inside

- A gallery table, an ingredient list with images, numbered steps and notes.
- Semantic HTML: headings, lists, a table, `<strong>` and `<i>`.
- Responsive images (`max-width: 100%`, `aspect-ratio`) and lazy loading, so the page fits a phone.

## Tech stack

HTML5 · CSS3 · GitHub Pages

## Run locally

Open `index.html` in a browser.
